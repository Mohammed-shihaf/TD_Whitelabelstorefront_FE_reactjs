# TD_Whitelabelstorefront_FE_reactjs

Standalone React (Vite) self-serve storefront frontend for the
**White-Label / Multi-Tenant Storefront** project type — a real
multi-component app (tenant banner + product grid), not a single bare
component.

Not connected to any backend or Angular app by default. The paired
standalone backend lives in `TD_Whitelabelstorefront_BE_nodejs`, and
the Angular enterprise storefront in
`TD_Whitelabelstorefront_FE_angularjs`. The fully connected version
lives in `TD_Whitelabelstorefront_BE_nodejs_FE_reactjs_FE_angularjs-`.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per React version (18, 20, 22, 24).
